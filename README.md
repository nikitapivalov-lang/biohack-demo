# BioHack

Интерактивная рабочая тетрадь для подготовки к ЕГЭ по биологии. Демонстрационная версия.

В проекте есть интерактивные схемы клетки, митоза и мейоза, тренажёры хромосомных наборов и репликации, теория, заметки и подборки заданий из открытого банка ФИПИ. Часть разделов пока находится в разработке.

## Публикация демо на GitHub Pages

1. Создайте репозиторий `biohack-demo`. Для GitHub Free выберите Public.
2. Загрузите в корень репозитория файлы `index.html`, `README.md` и `.nojekyll` из этого комплекта. Сам ZIP загружать вместо файлов не нужно.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Source: Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
5. После завершения публикации откройте ссылку, которую GitHub покажет в разделе Pages.

Для обновления демо заменяйте `index.html` в той же ветке. GitHub Pages опубликует обновление автоматически.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Устройство проекта

- `index.html` — сайт со встроенными схемами, изображениями, стилями и логикой занятий. Сборка и серверная часть не требуются.
- `.nojekyll` — отключает обработку статических файлов Jekyll.
- `README.md` — описание и инструкция.

Для оформления используются Tailwind CSS CDN и Google Fonts; при демонстрации нужен интернет. Прогресс и заметки сохраняются локально в браузере посетителя и не синхронизируются между устройствами. Учётных записей учеников в демо нет.

## Источники учебных материалов

Задания с пометкой ФИПИ взяты из открытого банка ЕГЭ по биологии; их исходные номера и источники указаны в интерфейсе. Ответы и объяснения тетради не являются официальными ключами ФИПИ. Ссылки на материалы уроков приведены в самих занятиях.
